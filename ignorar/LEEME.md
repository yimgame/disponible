# ignorar/

Carpeta para **datos sensibles o de producción**: exportes de GCG/JDE con datos de choferes, listas, el compose real
del servidor, backups, notas internas, etc.

**Todo lo que pongas acá queda fuera de git** (está en `.gitignore`), así que no se sube a GitHub.
Lo único que se versiona de esta carpeta es este `LEEME.md`.

Antes de un push conviene mirar `git status`: no tiene que aparecer nada de `ignorar/`.
